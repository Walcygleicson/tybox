# tybox

> Essential utility types for TypeScript.

`tybox` is a TypeScript utility type library, organized by category, designed to cover the most common everyday use cases without the need to rewrite the same types across project after project.

---

## Installation

```bash
npm install -D tybox
```

---

## Usage

```typescript
import type { NthParameter, DeepPartial } from 'tybox';
```

All types are exported directly from the package root.
